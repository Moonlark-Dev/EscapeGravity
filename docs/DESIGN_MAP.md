# 设计文档 → 实现对照

本文档逐条说明设计文档在发行版中的落点（文件 / 函数 / 数值），以及文档没有给出、由实现决定的细节。
数值常量集中在 `src/consts.gd`；内容表在 `src/defs.gd`。

---

## 1. 定位与核心循环

| 文档 | 实现 |
|---|---|
| 2D 俯视、物理驱动、无直接攻击的太空肉鸽 | `src/run.gd` 单局主控；玩家无攻击输入；唯一敌人伤害来源是敌方导弹 |
| 进入区域 → 攻击者出现 → 追踪导弹 → 诱导撞击 → 过载 → 掉落物质 | `spawn_enemy` → `enemy.step` → `missile.step` → `_resolve_collisions` → `damage_enemy` → `kill_enemy` → `scatter_matter_at` |
| 逐步深入更高威胁星域 | `depth += 1`（每次摧毁攻击者）；血量 `×(1+0.22(depth-1))`、射速 `×max(0.62, 1-0.035(depth-1))`、速度 `×(1+0.02(depth-1))`；每 5 层精英 ×1.6 |

无安全区时炮塔出生距离 1900~2400，满速（240）抵达约 8~10s；有安全区时出生在玩家—安全区连线的延长线上、安全区外侧，保证两个 HUD 方位标记同向。

| 加力 | 3× 推力（1140）、1.28× 极速（192）、槽 2.2s、0.7s 后回复、剩余 0.22 才可再启、1.2× 燃料 | `ship.step`：`boost_mult`（升级 ×1.07）、`boost_cap`（升级 ×1.1）、回充 1.6/s，迟滞 0.22 |
| 燃料 | 上限 240；推进 4/s，加力 8/s（文档） | 发行调整为上限 500；推进 4/s，加力 4.8/s（1.2×） |

| 移动端操作 | 摇杆 + 按钮 | `ui.gd` 触屏层：摇杆、加力、2 技能、物品格、暂停 |

## 3. 敌人通用规则

| 项 | 文档 | 实现 |
|---|---|---|
| 大小 | 非小型敌人比屏幕大 | 炮塔 R420（直径 840 > 720）；导弹巢 R300（作为第二个变体，见§10） |
| 视野外/内移动 | 240 / 18 | `enemy.step`：不在屏内 240，屏内 18；距离过近会反向微调 |
| 攻击欲望 | 视野内大幅提升 | 炮塔 5s（外）/1s（内）；巢 3.6s/1.5s；45% 单发，0.2s 间隔 |
| 刷新 | 屏幕外、未探索区、非小型不同时刷新 | `_find_enemy_spawn`：有安全区时沿玩家→安全区方向（外侧），否则 1900~2400；`!explored` 优先，避开天体/安全区/商店 |
| 每星域基础敌人 | 1 个炮塔 | 单敌人；`current_enemy` |
| 血条 | 顶部中间 | `ui._refresh_enemy`；视野外仍显示并标注距离 |
| 炮塔数值 | R420、HP50、导弹 25、速度 150、5s 脱锁、不可加力、脱锁不可再锁 | 同 |
| 锁定上限 | 3 枚；超出停火 | `locked_missile_count()`；炮塔 3、巢 4 |
| 过热停火 | 2.5s | 命中即 `overheated=true`，`overheat_timer=2.5` |
| 导弹入场 | 视野外时垂直于敌人-玩家连线进入 | 视野外：玩家侧向 820px；视野内：炮塔最近炮口 / 巢前向口，`R+14` 处出膛，角度朝向玩家 + 0.35s 提前量 |
| 导弹绕开敌人 | 锁定状态下自动尝试绕开敌人，避免刚发射就打自己 | `missile.step`：距敌人 <R+34 且航向向内时施加偏转；锁定时不与来源敌人碰撞 |

## 4. 基础导弹

| 项 | 文档 | 实现 |
|---|---|---|
| 速度 | 150 = 玩家基础移速 | `Missile.speed=150` |
| 转向 | 0.525 rad/s，转弯半径 ≈286 | 同；每帧角速度限制 |
| 锁定 | 进入屏幕后 5s 脱锁 | `seen` 由 `run.is_on_screen` 判定，`lock_timer>=5` → `unlock()` |
| 脱锁 | 只能直线，仍受天体引力，无法再锁定 | 脱锁后 `vel += gravity*0.9*dt`，不重锁（诱饵除外） |
| 伤害 | 对敌 25；对我 25（护盾 20 → 一击结束） | 同 |
| 生命周期 | 18s 自毁 | `MISSILE_LIFE=18` |
| 陨石引爆 | 导弹可被陨石引爆；玩家太近会磨损护盾 | 碰撞双方消失；玩家 135px 内 -2 |

## 12. 实现决定与新增

| 项 | 决定 | 理由 |
|---|---|---|
| 代币 | 独立货币计数（HUD 右上），不占物品栏 | 文档“代币也是一种物品”与 2 格基础物品栏、商店体验冲突；货币化更可玩 |
| 导弹入场 | 视野外侧向 820；视野内从外壳炮口 | 视野内从侧向生成会与炮塔脱节；从外壳出膛并用“锁定时不与来源碰撞”避免刚发射就自爆 |
| 新增技能 3 个 | 引力锚 / 相位滑行 / 诱饵信标 | 文档只给脉冲示例，但要求 2 槽且升级；需要内容深度 |
| 导弹巢 | R300 / HP40 / 3 发齐射 / 上限 4，与炮塔按 `depth%3==2` 交替 | 提供第二种非小型敌人，改变齐射节奏 |
| 精英 | 每 5 层，血量 ×1.6、齐射 +1 | 深度推进的可见威胁升级 |
| 商店重开 | 离开后 26s 在新未探索区刷新 | 文档只给初始距离；需要可持续经济 |
| 安全区牵引 | 无输入即生效，不限于燃料 0 | 文档“无动力时会把玩家吸进去”；燃料 0 时也成立 |
| 燃料耗尽倒计时 | 12s | 文档只说“判定结束”，未给时间；给玩家漂移/抓安全区的机会 |
| 一局上限 | 无（无限深度） | 肉鸽循环；记录最佳深度 |
| 存档 | 设置 + 最佳记录；无中途存档 | 发行版最小持久化；避免存档兼容负担 |
| 代币上限 | 99 | 防止数值溢出与图标溢出 |

# Escape Gravity · 资产清单（v1 几何占位版）

本文件是**资产契约**：引擎只加载图片/音频文件，任何实体、UI、背景都不得在运行时用
`_draw()`、`draw_*`、`ColorRect` 等方式现场绘制图形。后续换美术时，只要按同名同尺寸
（或同宽高比）替换 `assets/` 下的文件即可，无需改代码。

## 通用规范

- 全部图片 **RGBA PNG**，透明背景，抗锯齿（4× 超采样后 LANCZOS 缩放）。
- 画布尺寸如下表；主体不要贴边，四周留 8%~15% 透明内边距给辉光。
- 风格：**深空霓虹 / 矢量几何**。底色近黑（#05070f），主色电青 `#39E6FF`、紫 `#8B5CF6`、
  品红 `#FF3D81`、琥珀 `#FFB347`、薄荷 `#5CF2A8`。发光用「模糊叠加」做，不要写实照片纹理，
  不要像素噪点铺满画面，不要烘焙文字（logo 除外）。
- 光晕类素材请做成**中心亮、边缘全透明**，引擎会用 additive 混合 + `modulate` 上色，
  所以尽量画成**白色/浅青**，留出可染色空间。
- 不透明主体不要带外发光以外的黑色描边；整体保持干净。
- 每张素材请自检：透明通道正确、无意外白底、中心对齐、朝向正确（见各条）。

## D. 交付要求

- 生成脚本放在 `tools/`（Python，PIL + numpy），可直接重跑覆盖产物。
- 附一张 `docs/asset_preview.png` 联系表（contact sheet），按组排布并标注文件名。
- 所有文件必须实际生成到 `assets/` 对应目录下，尺寸与上表一致（±0 像素）。
- UI 九宫格素材的边框区域必须在 24px 内可拉伸（不出现明显拉伸变形）。
- 音频峰值不超过 -1 dBFS，避免削波；SFX 首尾各 5ms 淡入淡出。
